# StudyGo – Student Task Manager

## Deskripsi
StudyGo adalah website sederhana yang dirancang untuk membantu mahasiswa mengatur dan memantau tugas kuliah secara lebih terorganisir.

## Fitur
- Menambahkan tugas
- Mengedit dan menghapus tugas
- Menentukan mata kuliah
- Menentukan deadline
- Menentukan prioritas tugas
- Mengatur status pengerjaan
- Melihat progres tugas
- Filter tugas
- Tampilan kalender untuk membantu mengatur jadwal

## Teknologi
- HTML
- CSS
- JavaScript
- Antigravity IDE

## Tujuan
Website ini dibuat sebagai proyek tugas mandiri untuk mengeksplorasi dan mengembangkan kemampuan penggunaan Antigravity dalam pembuatan website.

## Pengembangan
Proyek akan dikembangkan secara bertahap dengan menambahkan fitur dan melakukan penyempurnaan berdasarkan hasil pengujian.
